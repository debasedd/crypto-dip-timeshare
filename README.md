## The joke

> I bought the dip, then the dip bought a dip, and now my portfolio is a timeshare in a chart that only goes down.

The setup is the move every trader recognises — buying the dip. The turn keeps dipping: the dip buys a dip of its own. The payoff lands the whole portfolio as a timeshare in a chart that only goes down. One sentence, one read, punchline at the end.
